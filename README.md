Coffee Button☕ 

Bean Button is a fun side project built to explore and learn more about JavaScript, React, and CSS. The application allows users to track coffee brews in real time, celebrate fellow brewers with kudos, and see the most recent coffee makers.

This is version 1.0 of the project.

🚀 Tech Stack
React - used for building the UI
JavaScript- Core programming language
CSS	- Styling and layout
Firebase Realtime Database - Used to store and fetch brew data in real-time
Miro - Used for planning, workflow mapping and feature brainstorming (Kanban-style task tracking)

📌 Project Overview
Development time: ~4 weeks
Purpose: Side project to deepen our understanding of React, JavaScript, component structure, state management, and basic UI/UX design
Focused on clean code, modular components, and experimenting with new features like adding a database for real-time updates and kudos interaction
We used Miro to organize tasks, set priorities, and visualize the workflow from idea to implementation

✨ Features (v1)
✔ Add your name and log a coffee brew
✔ Display recent brewers (limited to 5 latest)
✔ Give "kudos" to other brewers
✔ Timestamps for each brew using local time
✔ Responsive styling with basic CSS
✔ Real-time updates 

🛠 Installation & Setup
Clone the repo
git clone https://github.com/your-repo/bean-button.git
cd bean-button

Install dependencies
npm install

Start development server
npm run dev
